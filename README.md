# Exploratory-Data-Analysis-EDA-_Task5

Titanic Dataset - Exploratory Data Analysis (EDA)

## Objective

Perform Exploratory Data Analysis (EDA) on the Titanic dataset to uncover insights, relationships, and patterns in the data using statistical and visual methods.

## Tools Used

Python 3

Pandas

Matplotlib

Seaborn

Jupyter Notebook

## Files Included

EDA_titanic.ipynb : Jupyter notebook containing code and visualizations.

titanic.csv : Titanic dataset used for analysis.

## Key Analyses

Univariate Analysis: Histograms and boxplots to understand distributions of features like Age, Fare, and Sex.

Bivariate Analysis: Count plots and scatter plots to examine relationships (e.g., Survival vs Gender).

Multivariate Analysis: Pair plots and correlation heatmaps to identify feature interactions.

## Observations

Women had a significantly higher survival rate.

Passengers in 1st class were more likely to survive.

Younger passengers had better survival odds.

Fare and passenger class are strong predictors of survival.

## How to Run

Clone this repository or download the files.

Ensure you have Python and Jupyter installed.

Open EDA_titanic.ipynb in Jupyter Notebook.

Run all cells to generate plots and insights.
